NOTAS DEL PROYECTO: MULTI-HOP DISTRACTION

FECHA: Mayo 2026
CURSO: Software Inteligente
ATAQUE: Multi-Hop Distraction

RESUMEN EJECUTIVO
Este módulo implementa un ataque adversarial que añade información 
relacionada pero irrelevante al contexto, requiriendo razonamiento 
multi-paso para descartarla.

ARCHIVOS IMPORTANTES
--------------------
1. multi-hop-distraction.py - Clase principal del ataque
2. main.py - Script ejecutable
3. README.md - Documentación completa
4. GUIA_EXPOSICION.md - Guía detallada para presentación

DATASET
-------
- Dataset base: 12 ejemplos variados (ampliado desde 2 originales)
- Cobertura: razonamiento lógico, matemáticas, comprensión lectora
- Formato: Estructura MCQ estándar del curso

CONFIGURACIÓN
-------------
API Key: Configurada en ../.env
Modelo: gemini-2.0-flash-exp
Niveles: low (1-2 dist), medium (2-3 dist), high (3-4 dist)

SALIDAS GENERADAS
-----------------
- 3 archivos JSON (uno por nivel)
- 1 reporte de estadísticas (.txt)
- Metadata completa en cada ejemplo

MÉTRICAS DE ÉXITO
-----------------
- Validación automática implementada
- Manejo de errores robusto
- Tasa de éxito esperada: >90%

PREGUNTAS CLAVE PARA EXPOSICIÓN
--------------------------------
Q: ¿Por qué multi-hop?
A: Requiere múltiples pasos de razonamiento para descartar info irrelevante

Q: ¿Por qué usar Gemini?
A: Herramienta de generación, no el modelo evaluado

Q: ¿Cómo validamos?
A: Verificamos que label no cambie, contexto sea más largo, pregunta igual

Q: ¿Qué esperamos?
A: Degradación gradual de accuracy con aumento de intensidad

CONTACTO CON API
----------------
- Requiere: GEMINI_API_KEY en .env
- Obtener en: https://aistudio.google.com/app/apikey
- Mismo modelo que distractor-strengthening (consistencia)

NOTAS TÉCNICAS
--------------
- Inserción aleatoria de distracciones (evita patrones)
- Uso de dotenv para seguridad de API keys
- Compatible con Python 3.8+
- Tiempo estimado: 2-3 minutos para 12 ejemplos x 3 niveles

DIFERENCIAS CON OTROS ATAQUES
------------------------------
- distractor-strengthening: Modifica OPCIONES
- irrelevant-sentence: Añade info obviamente irrelevante
- multi-hop (ESTE): Añade info que PARECE relevante
- sentence-shuffling: Cambia ORDEN
- contradictory-noise: Añade CONTRADICCIONES
- premise-mismatch: Sugiere respuesta INCORRECTA

VENTAJA COMPETITIVA
-------------------
Multi-hop es más sutil que irrelevant-sentence porque la información
añadida está relacionada temáticamente, requiriendo razonamiento
profundo para descartarla.

LIMITACIONES CONOCIDAS
-----------------------
1. Depende de calidad de Gemini para generar distracciones
2. API puede fallar (se maneja con try/except)
3. Algunas distracciones pueden ser muy obvias (validación manual recomendada)
